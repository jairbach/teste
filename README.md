# Infográfico de Saudades — versão atualizada

## Publicação no GitHub Pages

**Envie o conteúdo desta pasta para a raiz da pasta publicada do repositório**, preservando esta estrutura:

- `index.html`
- `data/locais.geojson`
- `assets/planta-pagina-59.png`

Não envie apenas o arquivo ZIP: extraia-o primeiro. Se o seu site já tem um `index.html`, faça uma cópia de segurança e integre os recursos ao projeto existente antes de substituir arquivos.

O endereço `data/locais.geojson` é relativo ao `index.html`. No GitHub, confirme que o arquivo aparece exatamente como `data/locais.geojson` (nomes diferenciam maiúsculas e minúsculas). Depois do commit, aguarde a publicação e recarregue a página com Ctrl+F5.

Se o erro persistir, a mensagem na página agora mostrará o detalhe HTTP/caminho que falhou.
